          Signal FM — Colophon
          
        

        
Four stations
broadcasting
from nowhere.

        

          Signal FM is a pirate radio station that only exists while this tab is open. Nothing is recorded: every note
          is synthesised as you listen, every frame is a raymarched room printed in type. Turn the dial. Between the
          stations is the static, and the static is where it all comes from.
        

        

          
Rendering
WebGPU · WGSL
4 SDF raymarchers (pipeline overrides)
rgba16float, 2 × 2 texels / cell

          
ASCII pass
Sobel edges on depth → / \ | -
Bayer-dithered glyph ramp
Canvas2D atlas → copyExternalImageToTexture

          
Audio
Web Audio synthesis, no samples
oscillators · noise · biquads · delays
lookahead scheduler · comp → limiter
